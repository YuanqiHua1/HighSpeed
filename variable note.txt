"""
====================  参数修改说明（重要）  ====================

本脚本用于从 joetailfit 输出的 .pkl 尾部坐标文件中，
计算尾摆相关动力学参数（half-beats、频率、曲率、摆幅、左右偏向等）。

⚠ 修改参数前请阅读以下说明，否则可能影响统计结果一致性。

----------------------------------------------------------------
【1】输入输出路径
----------------------------------------------------------------
- folder_path:
  输入 .pkl 文件所在文件夹路径。

- output_folder:
  输出 .csv 文件保存路径。
  建议使用 os.makedirs(output_folder, exist_ok=True) 防止报错。

- filename:
  输出文件名前缀（不影响分析结果）。

----------------------------------------------------------------
【2】平滑参数（影响噪音与峰值检测）
----------------------------------------------------------------
- Box1DKernel(3)  或 frame_for_smoothing:
  移动平均平滑窗口大小（单位：帧）
    数值越大 → 更平滑，噪音更少，但可能削弱真实快速摆动
    数值越小 → 保留细节，但可能出现假峰

- x_smoothed[10:-10]:
  去除平滑造成的边缘效应
    增大 10 → 更安全但可用帧减少
    减小 10 → 时间范围更长但可能有边缘误差

⚠ 注意：裁剪后帧号已改变，如需对应原视频需加回偏移量。

----------------------------------------------------------------
【3】摆尾角度（Deflection）定义
----------------------------------------------------------------
当前定义：

    dx = tail_tip_x - base_point_x
    dy = tail_tip_y - base_point_y
    deflection = degrees(arctan2(dx, dy))

如果修改：
- frame[0] → frame[2]
  则改变参考基准点（从尾基改为更远端点）
  影响：角度幅值会变化，可能更稳定但数值不可直接与旧数据比较。

- frame[-1] 改为 frame[-2] 等
  表示使用更靠近尾根的点作为“尾尖”
  影响：角度振幅减小，噪音可能降低。

----------------------------------------------------------------
【4】曲率（Curvature）计算
----------------------------------------------------------------
曲率 k = 所有相邻尾段夹角之和。

如果修改：
- 尾段数量
- 是否取绝对值
- 段角计算方式

则 max_curvature / mean_curvature 会改变。

----------------------------------------------------------------
【5】峰值检测参数（决定 half-beat 数量）
----------------------------------------------------------------
使用 scipy.signal.find_peaks 检测左右峰。

关键参数：

- distance=10
  峰之间最小间隔（帧）
    增大 → 峰数量减少（防止重复计数）
    减小 → 峰数量增加（可能包含噪音）

- prominence=8
  峰强度阈值
    增大 → 只保留强摆尾
    减小 → 弱摆尾也被统计

- width=1
  控制峰宽判定

⚠ 这些参数直接影响：
    Nr_half_beats
    Freq_half_beats
    Movement_duration

----------------------------------------------------------------
【6】Active half-beat 过滤（去除回弹峰）
----------------------------------------------------------------
在 raw peaks 基础上进一步筛选 active peaks。

参数：

- min_amp_deg = 4.0
  如果某个峰的绝对摆幅 < 4°
   我们认为它太小，可能是噪音/回弹
   不把它当作真正 half-beat

- require_alternation=True
  强制 R-L-R-L 交替
    True  → 去除连续同侧峰（常为回弹）
    False → 保留同侧连续峰

- amp_ratio=0.4
  新峰幅度至少为前一峰的 40%
    增大 → 更严格，峰数减少
    减小 → 更宽松，峰数增加

当前定义：
    active peak 数量 = half-beat 数量

----------------------------------------------------------------
【7】运动持续时间（Movement_duration）
----------------------------------------------------------------
由 active peaks 的 left_ips / right_ips 决定。

如果修改峰检测或 active 过滤，
运动持续时间也会改变。

----------------------------------------------------------------
【8】Swimming 判定（游泳子集）
----------------------------------------------------------------
当前规则：

    abs(deflection) < 50°  → 视为 swimming

修改该阈值会影响：

- Swimming_duration
- Nr_half_beats_swimming
- HB10s_* 指标
- Swimming bias

建议：
    50° 常用于区分正常游泳与逃逸/爆发运动。
    根据实验需求可调整。

----------------------------------------------------------------
【9】HB10 / HB10s 指标
----------------------------------------------------------------
HB10_*:
  前 10 个 active half-beats（全部运动）

HB10s_*:
  前 10 个 swimming active half-beats

如果峰检测或阈值改变，
“前10”对应的峰会变化。

----------------------------------------------------------------
【10】左右偏向指标
----------------------------------------------------------------
- Bias_RL = R / L
- Laterality_Index = (R - L) / (R + L)

⚠ 若更改 dx 方向或坐标系，
正负方向会翻转，
Bias 和 LI 符号也会反转。

----------------------------------------------------------------
【11】重要提醒
----------------------------------------------------------------
当前代码已统一：
- movement 使用 active peaks
- swimming 也使用 active peaks
- 所有统计口径一致

如果修改为 raw peaks，
需保证全局与 swimming 使用同一体系，
否则会出现统计不一致。

================================================================
"""
